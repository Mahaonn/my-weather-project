# 🌤️ My Weather App

A responsive weather application that displays current weather data for any city using the OpenWeather API. Built with semantic HTML, modern CSS, and vanilla JavaScript.

## 🔧 Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6+)  
- Axios  
- OpenWeather API  

## ✨ Features
- 🔍 City-based weather search  
- 📡 Real-time temperature, humidity, wind speed  
- 🕒 Live clock with dynamic updates  
- 🌐 Deployed on Vercel  

## 📂 Project Structure

│ ├── main.css

## 🛠️ Installation & Local Setup

To run the project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/Mahaonn/my-weather-project.git
   cd my-weather-project

2. Open index.html in your browser No build tools required — it's a pure frontend project.

✅ Make sure you have internet access to fetch data from the OpenWeather API.
